# Nitin Mahlan — Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. For a local development server, use VS Code's Live Server extension.

## Personalize before publishing
Search `index.html` for these placeholders and replace them:
- `YOUR_EMAIL@example.com` — your professional email
- `https://github.com/` — your GitHub profile and each project's actual repository URL
- `https://www.linkedin.com/` — your LinkedIn profile

Also review the project descriptions and skill list so they accurately reflect the features you've implemented. Add a resume PDF link if you want recruiters to download your resume.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `nitin-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. In repository Settings → Pages, select deployment from the `main` branch and root folder.
4. Save and wait for GitHub Pages to publish your site.

No build step or package installation is required.
